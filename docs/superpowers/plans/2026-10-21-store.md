# Store (Phase 3): implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (controller) / superpowers:test-driven-development (each worker). The binding contract is `2026-10-21-store-contract.md`. Read it first. Field names, routes and codes come from there.

**Goal:** a barber adds products in the app, and customers buy them on `www.aibarber.org/shop/{slug}`. They pick pickup or flat-rate shipping and pay in the shop, by Cash App / Venmo / Zelle / PayPal, or by card through Stripe Checkout on the barber's connected account, with a 2% fee. The barber manages orders in a new Store tab, gets a push for each new order, and customers get confirmation, ready and shipped emails.

**Spec:** §5.3, §7.2, §9, §10, §12, §14 of `docs/superpowers/specs/2026-10-21-bookings-store-design.md`.

## Ground rules for every worker

### Worktrees

One per worker, off the base named below.

- **Disk is tight** (about 6 GB free). Never `npm install` in a worktree. Symlink the dependencies instead:
  - **Server:** `ln -s ~/AI-Barber/node_modules <worktree>/node_modules`
  - **App:** `ln -s ~/aibarber-ios/node_modules <worktree>/node_modules`
- **No new npm dependencies** in any worker. The app has `expo-image-picker`, `react-native-gesture-handler` and `reanimated` already. Reorder uses up/down arrows in a long-press "Arrange" mode, the same as the Services editor.
- **`~/aibarber-ios/src/web` is a byte-for-byte copy of the web repo. Never edit it.** It is refreshed only by `scripts/sync-web.sh`, after the server work is on `origin/main` (a controller step).

- Tests: `npx vitest run <paths>`; types: `npx tsc --noEmit -p .`. The tsc baseline is about 4112 errors, all in JSX under `src/book` because `@types/react` is missing; don't add new non-JSX ones.

### App

**`webhook.test.ts`** (`handleConnectEvent` with both deps faked)

- **Store routing:**
  - a `completed` store session never calls the appointment deps;
  - an appointment session (no store metadata) never calls the order deps;

- **Paid after cancel:** recorded without `paid_at`; the refund key is `refund-pac-{pi}`; `setOrderRefunded` is absolute.

- **Account mismatch:** ignored.
- **Expired:** `expireOrderHold` uses the compare-and-set; a no-op when already paid.
- **`charge.refunded`:** an appointment PI goes to the appointment path (unchanged); an order PI goes to `setOrderRefunded(amount_refunded)`; a lower total arriving late never lowers the value.
- **Failures:** a handler throw means the event is not recorded (`recordEvent` not called).
